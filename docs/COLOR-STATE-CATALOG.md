# Color-state catalog rules

Yellow is exact extraction. It must never summarize, infer, repair, complete, code from, or reinterpret missing source material.

Colors describe workflow state; they do not independently prove the underlying factual claim. Green requires concrete verification appropriate to the project. A reported historical success can remain in the catalog while still carrying a verification requirement.

The active block is Purple/Assimilation. The supplied inventory identifies StarQuest playback and ledger verification as a candidate for the next Orange decision, but the builder must not silently make that executive selection.
